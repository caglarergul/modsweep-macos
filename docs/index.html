Features Safety Install

One copy of every package. Not one per project.

modsweep is a Mac app for a folder full of JavaScript projects. It shows what node_modules costs you, finds why a project won't install, cleans safely, and lets npm and yarn projects share one pnpm store.

Download for Mac Free, for macOS 14 Sonoma or later on Apple Silicon and Intel.

Or install it with Homebrew:

brew install --cask caglarergul/tap/modsweep

Everything node_modules does to your disk, in one window.

Point modsweep at the folder that holds your projects. It scans them, explains them and cleans up after them.

Share

Keep each package version once

npm and yarn put a full copy of every package into every project. modsweep shows which versions repeat across your projects and moves the ones you pick to one shared pnpm store. Only two local files are added and git never sees them, every project is backed up first, and you can go back to npm or yarn any time.

Analyze

Know why a project won't install before you try

Lockfiles out of sync, two lockfiles, the wrong Node version, node-sass, old webpack on new Node, Next 16 with a webpack config, Prisma, a missing .env, Stencil store problems. Every finding comes with its fix.

See every project at a glance

Size of each node_modules, package manager, last activity and git state, plus your npm, pnpm, yarn and bun caches. The total sits in the menu bar.

Free space without losing anything

The node_modules folders and build caches (.next, .turbo, .angular, ios/build …) you pick go to the Trash, and Undo puts them back. Folders with a running Node process or files tracked by git are left alone.

Check that a project still builds

Installs the selected projects and checks dependencies, commands, typecheck, build and optionally a dev server, with a live log and a Stop button. Every file is put back afterwards.

Made for projects that are wired to real systems.

Testing a project should never touch production. These rules are always on.

  • Nothing is pushed or deployedScripts that mention deploy, publish, push, migrate, vercel or shopify never run during a test.
  • Databases stay out of reachDatabase, Redis and Mongo addresses from .env files point nowhere while a test runs.
  • Your files come backpackage.json, lockfiles and the git state are backed up before a test or a move and restored afterwards, also when you press Stop.
  • Crash-safeIf the Mac or the app stops halfway, modsweep restores the project on the next launch before it does anything else.
  • No process is left behindTest servers are stopped by process tree and by folder.
  • Nothing is deleted for goodClean moves folders to the Trash. Shared projects can go back to npm or yarn at any time.

Install

Download the DMG from the latest release, open it and drag modsweep to Applications. Every build is signed with Developer ID and notarized by Apple, so it opens without warnings.

All releases on GitHub

Requirements

macOS 14 Sonoma or later. Installing and verifying projects needs pnpm; moving projects to the shared store needs pnpm 10 or newer. npm, yarn and bun projects are all supported.

Homebrew

# install
brew install --cask caglarergul/tap/modsweep
# update
brew upgrade --cask modsweep
# remove the app and its data
brew uninstall --cask --zap modsweep

Privacy

No account, no analytics, no tracking. modsweep goes online only to install packages when you ask it to and, if you leave it on, to check Stencil stores during an analysis.
